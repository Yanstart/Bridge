\section*{Annexe B : Exemple de Bundle FHIR R4 émis par la passerelle}
\label{sec:annexe-bundle-fhir}
\addcontentsline{toc}{section}{Annexe B : Exemple de Bundle FHIR R4 émis par la passerelle}

Le Bundle ci-dessous est de type \texttt{transaction}. Il est issu d'une trame moniteur Philips IntelliVue MX450. Il contient trois ressources : Patient (référence simulée), Device (le moniteur lui-même) et Observation (la mesure SpO\textsubscript{2}).

\begin{lstlisting}[style=bridgejson, caption={Bundle FHIR R4 transaction émis par la passerelle pour une mesure SpO2.}, label={lst:bundle-fhir}]
{
  "resourceType": "Bundle",
  "type": "transaction",
  "entry": [
    {
      "fullUrl": "urn:uuid:patient-demo-001",
      "resource": {
        "resourceType": "Patient",
        "id": "demo-001",
        "identifier": [{
          "system": "urn:oid:2.16.840.1.113883.2.4.6.3",
          "value": "ROOM-12-DEMO"
        }]
      },
      "request": {"method": "PUT", "url": "Patient/demo-001"}
    },
    {
      "fullUrl": "urn:uuid:device-philips-mx450-001",
      "resource": {
        "resourceType": "Device",
        "id": "philips-mx450-001",
        "manufacturer": "Philips",
        "modelNumber": "IntelliVue MX450"
      },
      "request": {"method": "PUT", "url": "Device/philips-mx450-001"}
    },
    {
      "fullUrl": "urn:uuid:obs-spo2-12345",
      "resource": {
        "resourceType": "Observation",
        "status": "final",
        "code": {
          "coding": [{
            "system": "http://loinc.org",
            "code": "59408-5",
            "display": "Oxygen saturation in Arterial blood by Pulse oximetry"
          }]
        },
        "subject": {"reference": "Patient/demo-001"},
        "device": {"reference": "Device/philips-mx450-001"},
        "effectiveDateTime": "2026-05-04T14:23:17Z",
        "valueQuantity": {
          "value": 96,
          "unit": "%",
          "system": "http://unitsofmeasure.org",
          "code": "%"
        }
      },
      "request": {"method": "POST", "url": "Observation"}
    }
  ]
}
\end{lstlisting}
